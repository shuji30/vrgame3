# 不具合・不満の一覧(vrgame3)

企画書 `docs/plan.md` の M4「不具合・不満の一覧」の表です。試遊の指摘、作者が遊び込んで気になった点、テスターのレビューで出た問題のうち未修正のものを入れます。

判断の基準(企画書より):
- 酔い・事故・進めなくなる不具合は、必ず「直す」にする。
- Inspector の値で直るものは、値を変えて直す。
- 新しい遊びや種目が要るものは「直さない」にする。理由の欄に、将来の候補として書く。

完成の条件:すべての行の判断が「直す(直した)」か「直さない」になっていて、「未定」と、まだ直していない「直す」が残っていないこと。
